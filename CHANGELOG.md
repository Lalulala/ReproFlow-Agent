# Changelog

All notable changes to ReproFlow are documented here.

## 0.2.0 - 2026-08-31

### Added

- Conversational Streamlit UI with persistent, automatically named experiment chats.
- Repository Agent for bounded source inspection, reviewable code diffs, and experiment planning.
- Dependency Preflight with project-owned uv environments and an approval-gated Repair Agent.
- Experiment-scoped Results, Evidence, Knowledge, and Memory views.
- Chinese human-readable plans, reports, and Evidence explanations.
- Deterministic 20-case Agent acceptance suite and GitHub Actions CI.
- Architecture, security, contribution, and two-minute demonstration documentation.

### Changed

- Consolidated structured workflow and repository execution behind the conversational Agent.
- Improved command, path, source-drift, secret-redaction, timeout, and artifact guardrails.

## 0.1.0 - 2026-08-24

- Initial reproducible sklearn experiment loop, structured plans, safe runner, metrics aggregation,
  checkpoint recovery, local RAG, experiment memory, reporting, and Evidence Registry.
